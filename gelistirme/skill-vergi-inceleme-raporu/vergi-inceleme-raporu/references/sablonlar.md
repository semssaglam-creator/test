# Cümle Kalıpları

Sahada kullanılan üç belgeden çıkarılmıştır. `<köşeli>` yerler doldurulur;
doldurulamıyorsa **kırmızı** yer tutucu olarak bırakılır.

Kısaltmalar: **M** = mükellefin anılışı ("mükellef kurum" / "mükellef"),
**D** = dönem adı ("hesap dönemi" / "takvim yılı").

```

```

